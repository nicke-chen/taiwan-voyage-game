# 大航海時代：臺灣任務

這是一個給國小高年級使用的單頁互動學習遊戲。

## GitHub Pages 預計網址
https://nicke-chen.github.io/taiwan-voyage-game/

## 部署方式
1. GitHub → Settings → Pages
2. Build and deployment 選 `Deploy from a branch`
3. Branch 選 `main`
4. Folder 選 `/ (root)`
5. 按 Save
6. 等待 GitHub Pages 完成發布

發布後，學生可直接開啟上方網址，或掃描 QR Code 進入遊戲。
